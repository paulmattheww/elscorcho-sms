El Scorcho Household Alerts — last updated July 24, 2026

  1. Program description. El Scorcho Household Alerts, sent from (970) 423-2661, delivers weekly meal plan summaries, grocery order status updates, and shopping substitution questions by SMS/MMS to the two members of the program owner's household.

  3. Message frequency. Message frequency varies; typically 2–10 messages per week, concentrated on weekends.
  4. Fees. Message and data rates may apply. If you have any questions about your text plan or data plan, it is best to contact your wireless provider.
  5. Opt-out. You can cancel the SMS service at any time. Just text STOP to (970) 423-2661. After you send the SMS message STOP to us, we will send you an SMS message to confirm that you have been unsubscribed. After this, you will no longer receive SMS messages from us. If you want to join again, just sign up as you did the first time or text START and we will start sending SMS messages to you again.
  6. Help. If you are experiencing issues with the messaging program you can reply with the keyword HELP for more assistance, or you can get help directly at paulmattheww@gmail.com.

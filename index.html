El Scorcho Household Alerts 🌶️

A private SMS program that sends weekly meal plan summaries, grocery order status updates, and shopping substitution questions to the two members of the program owner's household.

How to join

Text START to (970) 423-2661 to subscribe to El Scorcho Household Alerts. This program is intended solely for the two members of the program owner's household.

By subscribing you agree to receive recurring SMS/MMS messages about meal planning and grocery shopping. Message frequency varies (typically 2–10 messages per week). Message and data rates may apply. Reply STOP at any time to cancel and HELP for help. Consent is not a condition of any purchase.
